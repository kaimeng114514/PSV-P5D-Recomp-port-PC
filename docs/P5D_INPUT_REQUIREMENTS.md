# P5D 移植版 键鼠操作要求（用户验收标准）

> 本文件是用户对各界面键盘/鼠标操作提出的**明确要求**，作为实现与验收的唯一依据。
> 测试环境：桌面 `P5D Windows移植版启动器.bat` → 启动器 → 游戏（2K 全屏）。
> 最近更新：2026-11-08（M1522）

## 总原则

1. **PC 键鼠优先**：游戏启动即禁用原 PS 手柄/PS 键位方案，由端口在代码层把键盘/鼠标映射成游戏按键（`window_input`/`ctrl_peek` 层），不依赖手柄。
2. **禁止靠画面识别/猜画面**：界面判定必须使用**代码层状态**（app state、作业/进程名、场景状态字、内存中的菜单选中索引等），不得用截图模板、红条检测等画面识别来做输入决策。
3. **返回一律用鼠标右键**；不用退格键作为"返回"。
4. 鼠标左键 = 游戏原生的确认（Circle）；右键 = 原生返回（Cross）。
5. 滚轮 = 游戏原生列表移动（一格 = 一步），并同步端口自己的选中行计数。

## 设置界面（统一要求）

**无论是主菜单进入「設定」、打歌暂停菜单进入「設定」，还是社群剧情暂停菜单进入「設定」，设置界面的操作完全一致：**

| 操作 | 要求 |
|---|---|
| Q / E | 调整数值（D-pad 左/右） |
| 鼠标滚轮 | 选择行 |
| 鼠标左键 | 确认 |
| 鼠标右键 | 返回（回到进入前的界面：主菜单 / 暂停菜单） |
| 键盘 Alt | 弹出「恢复预设/重置所有选项」确认框（左键=是，右键=否） |

下面的第 5)、7)、8) 条都以此为准。
## 各界面要求

### 1) 主菜单

| 操作 | 要求 |
|---|---|
| 鼠标滚轮 | 选择（上下移动高亮项） |
| 鼠标左键 | 确定（进入当前高亮项） |
| 鼠标右键 | 返回 |

### 2) 选歌界面

| 操作 | 要求 |
|---|---|
| 鼠标滚轮 | 选歌（列表滚动/选择） |
| 鼠标左键 | 确认（进入所选歌曲/换装流程） |
| 鼠标右键 | 返回（逐级：服装页→选歌→主菜单） |
| **Q / E** | **调整难度**（EASY / NORMAL / HARD 难度页签，D-pad 左/右） |

### 3) 打歌界面

| 操作 | 要求 |
|---|---|
| **Q / A / Z / O / K / M** | 打歌按键（Q=上、A=左、Z=下、O=△、K=○、M=×；D=右、J=□ 为补充） |
| **ESC** | 调出暂停菜单 |

### 4) 暂停菜单（打歌中按 ESC）

| 操作 | 要求 |
|---|---|
| 鼠标滚轮 | 选择（設定/重試/自訂遊玩/放棄/返回） |
| 鼠标左键 | 确认 |
| 鼠标右键 | 返回（关闭暂停回到游戏） |

### 5) 暂停菜单 →「設定」设置页

| 操作 | 要求 |
|---|---|
| **Q / E** | 调整数值（D-pad 左/右） |
| 鼠标滚轮 | 选择行 |
| 鼠标左键 | 确认（进入/选择该行） |
| 鼠标右键 | 返回（回到暂停菜单） |
| **键盘 Alt** | **触发"恢复预设/重置所有选项"确认框**（确认/取消用鼠标左键=是、右键=否） |

### 6) 社群界面

| 操作 | 要求 |
|---|---|
| 鼠标滚轮 | 选择（角色/事件列表） |
| 鼠标左键 | 确定 |
| 鼠标右键 | 返回 |
| **Q / E** | 切换角色（L/R 肩键） |

### 7) 社群界面按 ESC → 暂停界面

| 操作 | 要求 |
|---|---|
| ESC | 调出暂停界面（社群剧情内） |
| 暂停界面 | 操作同第 4)、5) 条：滚轮选择 / 左键确认 / 右键返回；进设置后 Q/E 调整 + 滚轮选择 / 左键确认 / 右键返回 |

### 8) 主菜单 →「設定」（CONFIG）设置页

| 操作 | 要求 |
|---|---|
| **Q / E** | 调整数值 |
| 鼠标滚轮 | 选择行 |
| 鼠标左键 | 确认 |
| 鼠标右键 | 返回（回主菜单） |
| **键盘 Alt** | **触发"恢复预设/重置所有选项"确认框**（确认/取消用鼠标左键=是、右键=否） |

## 端口键位映射现状（实现参考）

| 场景 | 键位 |
|---|---|
| 菜单/剧情（MENU） | 方向键=移动；Space/Enter=确定(○)；Backspace=返回(×)；Esc=START；Q/E=L/R；Tab=SELECT |
| 打歌（GAME） | Q=上、A=左、Z=下、D=右；O=△、K=○、M=×、J=□；Esc=START(暂停)；U/I=L/R |
| 选歌（SONG） | 方向键/Q=左、E=右（难度）；Space/Enter=确定；Backspace/Esc=返回 |
| 社群（COMMU） | 方向键=移动；Space/Enter=确定；Backspace=返回；Q/E=L/R（切换角色） |
| 设置（CONFIG） | 方向键=选择；Q/E=左右（数值）；Space/Enter=确定；Backspace/Esc=返回 |


## 实现架构（M1522：代码级界面识别 + 输入切换）

1. **启动即 PC-only**：忽略所有 SDL 手柄事件（原 PS 手柄方案被禁用；`RECOMP_ALLOW_PAD=1` 仅供测试），游戏只从端口的键盘/鼠标映射得到按键。
2. **屏幕状态服务（Screen State Service）**：每帧由游戏自己的代码状态判定当前界面，**不使用任何画面识别**：
   - 我们自己的暂停/设置 latch（谁打开的暂停，谁负责关闭）
   - **游戏作业链表扫描**（0x815554C4，每 150ms）：commuMain / MusicSelect / ConfigStartEffect / TutorialMain / result / mainMenuP5 / replay dance / danceVoiceSub / Dancig…
   - **app state**（0x813B01A8 链）：1=initread、3=COMMU、4=TUTORIAL（按菜单处理）、5=MAIN MENU、6=TITLE
   - 舞池作业流；最后是代码级场景标志
   - 3 帧去抖；每次切换打印 `[SCR] input screen -> <名称>`（便于日志验收）
3. **输入行为按屏幕切换**（日志可证）：
   - 菜单类（title/main/commu/tutorial/song/result/pause/settings/story）：滚轮=原生列表步进；左键=确认（Circle）；右键=返回（Cross，锁存；暂停时按我们自己的行计数退出）
   - 打歌界面：不拦截滚轮/鼠标，键盘走 Q/A/Z/O/K/M 映射，ESC=START（暂停）
   - 设置页（无论从哪进入）：同一套映射；Q/E=调整；Alt=恢复预设确认框
   - 退出某界面进入另一界面时，下一帧即切换到新界面的键位（`[SCR]` 日志显示切换）
4. **选中行**：端口用"自己发送的步进"计数（滚轮/方向键）维护当前行；暂停菜单退出与点击目标使用它。下一步（纯代码）定位游戏内存中的选中索引后改为直接读写，彻底消除计数漂移。
## 验收方式

- 启动器真实路径（桌面 bat），2K 全屏；
- 每项用日志（`[KEY]`/`[MOUSE]`/`[UI] wheel`/`[SCENE]`/`input: profile`）＋截图证明；
- 里程碑文档（P5D_MASTER）记录每次修复与证据。

## 实现架构（M1523：输入判定已改为纯代码，全部用游戏作业名）

用 `RECOMP_JOBDUMP=1` 抓取了游戏作业链表的全部作业名，每个界面都有游戏自己的"身份证"：

| 界面 | 代码级证据（游戏作业名） |
|---|---|
| 主菜单 | `main menu p5` / `mainmenu load` |
| 选歌 | `MusicSelectMain` |
| 打歌 | `DanceProcess` / `DanceMemberPose` / `mns` / `danceVoiceSub` |
| 暂停菜单 | `pause menu` |
| 设置页 | `config menu` / `ConfigStartEffect` |
| 社群 | `commuMain` |
| 社群剧情 | `evtSceneManager` / `evtSMProcess` / `evtSpeakerManager` |
| 标题 | `title` / `title sequence` / `titleDraw` |
| 结算 | `result` |

- 界面识别服务 = 作业名证据（按屏幕优先级）+ app state；**画面模型不再参与输入决策**（只在代码状态未知时做诊断显示）
- **ESC**：设置页→设置退出、暂停→关闭暂停、打歌/剧情→打开暂停、菜单→返回
- **Q/E**：选歌→难度、暂停/设置→数值、社群/剧情→切角色、主菜单/标题/结算→肩键
- **鼠标**：滚轮=列表步进、左键=确认、右键=返回（画面鼠标悬停/点击路径在 PC-only 下已禁用）
- 暂停"是否打开"以我们自己的开关为准（`pause menu` 作业在打歌时也会预载，不能当锁存源）
- 日志：`[SCR] input screen -> <界面>`（每次切换）、`[KEY] Q/E -> ... scr=<界面>`、`[MOUSE] lmb/rmb`、`[EV] esc -> ... (code screen)`

未完成：**主菜单选中行号**仍用端口自计数（滚轮/方向键步进），滚动与游戏高亮偶发差一行；下一步做纯代码的"选中索引"定位（写候选值 + 按 Circle + 看出现的作业名验证，不用画面），之后滚轮/点击/设置页识别全部零漂移。
